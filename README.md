# ShortVideoConsultant 🎯

> **1 个 Gemini Gem = 10 位短视频专家。你问什么，它自动匹配对应专家来回答。**
> **1 Gemini Gem = 10 short video consultants. Just ask, it routes to the right expert.**

---

## 这是什么？

一个**全能式 Gemini Gem 提示词**。体内融合了 10 位不同领域的短视频专家：

| # | 专家 | 能帮你解决 |
|---|------|-----------|
| 🔍 | 赛道诊断师 | 该做什么赛道、选什么领域 |
| 🎨 | 视觉总监 | 画面不好看、调色、字体、封面 |
| 🎣 | Hook工程师 | 视频开头怎么写、完播率低 |
| ✍️ | 脚本编剧 | 脚本、文案、剧本 |
| ⚙️ | 制作顾问 | AI工具推荐、工作流、省时间 |
| 📊 | 算法分析师 | 流量、平台算法、发布时间 |
| 📅 | 内容规划师 | 30天内容排期、发布节奏 |
| 🔥 | 趋势劫持者 | 蹭热点、追趋势 |
| 💰 | 变现顾问 | 怎么赚钱、变现路径 |
| 🚀 | 启动教练 | 从0开始、新手起号 |

**工作方式**：你问一个问题 → 它自动判断属于哪个领域 → 先反问 2 个问题收集信息 → 再给你完整方案。

---

## 使用方法

### 在 Gemini 里用
1. 打开 https://gemini.google.com
2. 左侧 **Gem** → **创建 Gem**
3. 把 `gem-ready.md` 的内容复制粘贴作为**系统指令**
4. 取名「短视频顾问」→ **保存**
5. 对话开始！比如问「我是新手，想做短视频赚钱」

### 在 Hermes Agent 里用
```
@Hermes 加载 gemini-viral-video-prompts
我是新手，想做短视频赚钱
```
